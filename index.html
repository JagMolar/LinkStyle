Edita tus textos para LinkedIn

Desde aquí puedes dar distintos tipos de estilos a tus textos y destacar tu contenido a publicar en LinkedIn. Será cuestión de copiar y pegar!.

Los caracteres con tildes o la 'ñ' no tienen sustituto en UNICODE, por lo que se verán sin formato. 0 / 150

¿Porqué utilizar esta herramienta para dar estilos en LinkedIn?

LinkedIn nos permite publicaciones de hasta 3000 caracteres, podemos incluir emojis, pero no permite resaltar de forma nativa, textos con formatos. Por ello, si necesitas resaltar el contenido en tu feed, puedes ayudarte desde esta misma página. Para ello, hemos dispuesto hasta 150 caracteres, evitando que así que se utilice de manera extensiva y pierda el valor del resaltado.

¿Cómo funciona?

Solo tenemos que introducir los textos que deseamos resaltar en el cuadro superior y automáticamente, tendrás a mano el texto modificado para copiar y pegar en tu publicación.

Solo utilizamos un poco de JavaScript para sustituir el texto por caracteres UNICODE, de forma transparente. Al ser una sustitución, no es perfecto, pero se consigue un gran resultado. Puedes revisar todo el proyecto desde el enlace de GitHub (Y si quieres, clonarlo para uso en local).

¿Quieres algún consejo para sobresalir en LinkedIn?

Ante todo, recuerda que debes publicar contenido relevante. No todo es Titulares con negrita y emojis 😁.

El buscador interno de LinkedIn puede tener dificultades para indexar estas palabras. Si escribes "Estrategia" en negrita Unicode, es posible que no aparezcas cuando alguien busque la palabra "Estrategia" normal.

Además, los lectores de pantalla para personas con discapacidad visual no leen estas letras como "Hola". A menudo las leen como "Símbolo matemático negrita H, Símbolo matemático negrita O...". Esto hace que tu contenido sea invisible para personas ciegas.

Mi consejo: Utiliza estos resaltados en titulares o elementos que no influyan en SEO.
